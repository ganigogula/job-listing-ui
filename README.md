# Job Listing UI

A responsive job listing interface built using HTML, CSS, and JavaScript. This project displays job cards and allows users to view job details through interactive UI components.

---

##  Features

- Responsive job listing layout  
- Interactive job cards  
- Dynamic job detail panel on click  
- Sidebar navigation toggle  
- Clean and structured UI design  

---

##  Tech Stack

- HTML  
- CSS  
- JavaScript (jQuery)
